# 코드 품질 규칙

## 단일 책임 원칙 (SRP)

- 모든 함수, 컴포넌트, 모듈은 하나의 역할만 수행한다.
- 컴포넌트가 데이터 fetching + 렌더링 + 비즈니스 로직을 모두 담당하면 안 된다.
- 커스텀 훅으로 로직을 분리하고, 컴포넌트는 렌더링에 집중한다.

```
컴포넌트 → 렌더링만
커스텀 훅 → 상태/비즈니스 로직
서비스 모듈 → API/알고리즘 연산
```

## 매직 넘버 / 매직 스트링 금지

- 의미를 알 수 없는 숫자나 문자열을 코드에 직접 쓰지 않는다.
- 상수 파일(`src/constants/`)에 이름을 붙여 관리한다.

```ts
// 금지
if (score > 3) { ... }
collection.get("words")

// 허용
const EASY_THRESHOLD = 3;
const COLLECTION_WORDS = "words";
if (score > EASY_THRESHOLD) { ... }
```

## 코드 간결성

- 함수는 화면 한 페이지를 넘기지 않도록 작성한다 (대략 40줄 이하).
- 중복 로직은 즉시 함수로 추출한다. 같은 패턴이 3회 이상 반복되면 반드시 추출한다.
- 불필요한 주석은 작성하지 않는다. 코드 자체가 의도를 드러내야 한다.
- 조기 반환(early return)을 적극 활용해 중첩을 줄인다.
