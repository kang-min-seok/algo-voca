# 문서화 규칙

## 진행 내용 문서화 의무

개발이 완료된 Phase 또는 주요 작업은 반드시 해당 Phase 문서에 기록한다.

기록 항목:
- 완료한 작업 목록 (체크박스로 표시)
- 구현 과정에서 내린 주요 결정과 그 이유
- 발생한 문제와 해결 방법
- 다음 Phase에 전달할 주의 사항

## 문서 위치

| 문서 종류 | 위치 |
|-----------|------|
| 개발 계획 | `docs/plan/` |
| 규칙 | `docs/rules/` |
| API 명세 | `docs/api/` (Phase 3 이후 생성) |
| 알고리즘 연구 | `docs/research/` (Phase 2 이후 생성) |

## 문서 업데이트 시점

- Phase 시작 전: 해당 Phase 문서의 목표와 세부 계획 확정
- Phase 완료 후: 완료 체크박스 업데이트 + 회고 내용 기록
- 계획 변경 시: index.md의 변경 이력 섹션에 날짜와 이유 기록
