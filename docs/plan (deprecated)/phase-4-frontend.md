# Phase 4 — 프론트엔드 개발

## 목표

사용자가 플래시카드를 통해 영단어를 학습할 수 있는 UI를 구현한다.
회원가입 시 직군을 수집하고, 추천받은 10개 단어를 플래시카드로 제시한다.

## 화면 목록

| 화면 | 경로 | 설명 |
|------|------|------|
| 랜딩 | `/` | 서비스 소개 및 로그인/회원가입 버튼 |
| 회원가입 | `/signup` | 이메일 + 비밀번호 + 직군 선택 |
| 로그인 | `/login` | 이메일 + 비밀번호 |
| 홈 | `/home` | 오늘의 학습 현황 + 학습 시작 버튼 |
| 플래시카드 | `/study` | 추천 단어 10개 순차 학습 |
| 학습 결과 | `/result` | 오늘 학습 결과 요약 |

## 컴포넌트 설계

### FlashCard 컴포넌트

핵심 인터랙션:
- 앞면: 영단어 표시
- 뒷면(클릭 후): 한국어 뜻 + 예문 표시
- 하단 버튼: "알고있음" / "모름"

```
FlashCard
├── CardFront (영단어)
├── CardBack (뜻 + 예문)
└── AnswerButtons (알고있음 / 모름)
```

## 직군 선택 UI

회원가입 시 직군을 선택하는 화면. 단일 선택.

```
[ ] 프론트엔드 개발자
[ ] 백엔드 개발자
[ ] DevOps / 인프라 엔지니어
[ ] 풀스택 개발자
[ ] 기타 (직접 입력)
```

## 완료 기준

- 회원가입 → 로그인 → 학습 시작 → 10개 카드 완료 → 결과 화면 흐름 완전 동작
- 플래시카드 앞/뒤 전환 정상 동작
- "알고있음" / "모름" 선택 후 다음 카드로 자동 이동
- 모바일 화면(375px)에서 레이아웃 깨지지 않음
