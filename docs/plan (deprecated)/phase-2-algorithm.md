# Phase 2 — 핵심 알고리즘 개발

## 목표

추천 엔진의 세 가지 핵심 알고리즘을 연구하고 구현한다.
각 알고리즘의 출력값을 합산하는 점수 함수를 설계하여 최종 추천 로직의 뼈대를 완성한다.

## 알고리즘 1 — 직군 관심사 기반 코사인 유사도

### 개요

사용자가 선택한 직군과 단어 사이의 의미적 유사도를 계산한다.

### 구현 방식

1. 사용자 직군 프로필을 벡터로 표현 (직군 대표 임베딩)
2. 단어 임베딩과 직군 벡터 간 코사인 유사도 계산
3. 근사 최근접 이웃(ANN) 알고리즘으로 후보군 빠르게 추출

```
코사인 유사도 = (A · B) / (|A| × |B|)
```

### 고려 사항

- 임베딩 모델 선택: OpenAI `text-embedding-ada-002` 또는 `sentence-transformers` 로컬 모델
- ANN 라이브러리 후보: FAISS, Annoy, hnswlib
- Firebase Functions 환경에서의 메모리/속도 제약 검토 필요

## 알고리즘 2 — SM-2 기반 복습 우선순위

### 개요

에빙하우스 망각 곡선을 기반으로 각 단어의 다음 복습 시점과 긴급도를 계산한다.

### SM-2 핵심 변수

```
EF (Ease Factor): 단어의 학습 난이도 지수, 초기값 2.5
I (Interval): 다음 복습까지의 일수
n (repetitions): 연속 정답 횟수
q (quality): 사용자 응답 품질 (0: 모름 / 1: 알고있음)
```

### 알고리즘 흐름

```
if q == 0 (모름):
    n = 0
    I = 1

if q == 1 (알고있음):
    if n == 0: I = 1
    if n == 1: I = 6
    if n >= 2: I = round(I × EF)
    EF = EF + (0.1 - (1-q) × 0.08)  # EF 최솟값 1.3
    n += 1

SM2_우선순위 = max(0, 오늘 - 다음복습일) / I   # 값이 클수록 복습 긴급
```

### 사용자 학습 기록 스키마 (Firestore)

```ts
interface UserWordRecord {
  userId: string;
  wordId: string;
  easeFactor: number;    // 초기값 2.5
  interval: number;      // 일 단위
  repetitions: number;
  nextReviewDate: Date;
  lastAnswered: Date;
}
```

## 알고리즘 3 — 2단계 필터링 추천 엔진

### 개요

전체 단어 DB에서 효율적으로 10개 단어를 추출하는 파이프라인 설계.

```
[전체 단어 DB]
      ↓ 1단계: ANN으로 관심사 유사 후보 50개 추출
[후보 50개]
      ↓ 2단계: 추천 점수 계산 후 상위 10개 선택
[최종 10개]
```

### 추천 점수 공식

```
score = w1 × cosine_similarity + w2 × importance + w3 × sm2_priority
```

| 항목 | 초기 가중치 |
|------|------------|
| w1 (직군 연관도) | 0.4 |
| w2 (단어 중요도) | 0.3 |
| w3 (SM2 복습 우선순위) | 0.3 |

가중치는 Phase 6에서 실험적으로 최적화.
