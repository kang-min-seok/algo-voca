# Phase 5 — 통합 및 테스트

## 목표

프론트엔드와 백엔드를 연결하고, 전체 서비스가 실제 환경에서 정상 동작함을 검증한다.
Cloudflare Pages에 배포하여 실제 사용자 흐름을 테스트한다.

## 통합 체크리스트

### 인증 연동

- [ ] 회원가입 시 Firebase Auth 계정 생성 + Firestore 유저 프로필 저장 동시 처리
- [ ] 로그인 상태 유지 (새로고침 후에도 로그인 유지)
- [ ] 로그아웃 처리 및 리다이렉트

### 추천 API 연동

- [ ] `/home` 진입 시 `recommend` API 호출
- [ ] 10개 단어 응답을 FlashCard 세션에 올바르게 전달
- [ ] API 로딩 상태 표시 (스켈레톤 또는 스피너)
- [ ] API 오류 시 사용자 친화적 메세지 표시

### 학습 결과 저장 연동

- [ ] "알고있음" / "모름" 버튼 클릭 시 `answer` API 호출
- [ ] 세션 완료 후 `/result` 화면에 정답률 표시
- [ ] 같은 날 재학습 방지 또는 허용 여부 결정

## 배포 환경 설정

### Cloudflare Pages

- [ ] GitHub 저장소와 Cloudflare Pages 연결
- [ ] 환경 변수 (Firebase 설정 키) Cloudflare에 등록
- [ ] `pnpm build` 결과물이 정상 배포되는지 확인
- [ ] SPA 라우팅을 위한 `_redirects` 파일 추가

### Firebase

- [ ] Firestore 보안 규칙 프로덕션 환경에 적용
- [ ] Firebase Functions 프로덕션 배포
- [ ] Firebase 사용량 모니터링 설정

## 엔드-투-엔드 테스트 시나리오

| 시나리오 | 기대 결과 |
|----------|----------|
| 신규 유저 회원가입 (프론트엔드 선택) | 프론트엔드 관련 단어 위주로 10개 추천 |
| 모든 카드 "모름" 선택 | 다음 세션에서 같은 단어 재등장 확률 높음 |
| 모든 카드 "알고있음" 선택 | 다음 세션에서 새로운 단어 등장 |
| 비로그인 상태로 `/study` 직접 접근 | 로그인 페이지로 리다이렉트 |

## 완료 기준

- 실제 배포된 Cloudflare Pages URL에서 전체 시나리오 동작 확인
- Firebase Functions 응답 시간 평균 2초 이하
- 콘솔 오류 없이 전체 학습 세션 완료 가능
