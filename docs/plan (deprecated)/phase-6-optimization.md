# Phase 6 — 알고리즘 최적화 및 연구

## 목표

추천 엔진의 가중치를 실험적으로 조정하여 최적의 추천 품질을 달성한다.
이 Phase는 프로젝트의 핵심 연구 목표에 해당한다.

## 최적화 대상 공식

```
score = w1 × cosine_similarity + w2 × importance + w3 × sm2_priority
```

초기 가중치: `w1=0.4, w2=0.3, w3=0.3`

## 실험 설계

### 실험 변수

| 변수 | 탐색 범위 |
|------|----------|
| w1 (직군 연관도) | 0.2 ~ 0.6 |
| w2 (단어 중요도) | 0.1 ~ 0.5 |
| w3 (SM2 우선순위) | 0.1 ~ 0.5 |
| 조건 | w1 + w2 + w3 = 1.0 |

### 평가 지표

- **학습 효율**: 같은 단어를 반복 틀리는 비율 감소
- **커버리지**: 직군 관련 필수 단어를 빠짐없이 노출하는 비율
- **만족도**: 사용자의 주관적 "오늘 추천이 적절했나" 피드백 (별점)

### 실험 방법

1. 가중치 조합 A, B, C를 사전 정의
2. 소규모 테스트 그룹에 각각 다른 가중치 적용
3. 2주 후 평가 지표 비교
4. 최적 가중치 선정

## 추가 개선 항목

### 신규 유저 콜드 스타트 문제

- 학습 이력이 없는 신규 유저는 SM-2 우선순위가 의미 없음
- 해결안: 신규 유저의 경우 초반 N세션은 `w3=0`, `w1+w2=1.0` 적용

### 임베딩 모델 비교

| 모델 | 장점 | 단점 |
|------|------|------|
| OpenAI ada-002 | 고품질 | 비용 발생 |
| sentence-transformers | 무료/로컬 | 품질 낮을 수 있음 |
| 파인튜닝 모델 | 도메인 최적화 | 학습 리소스 필요 |

### SM-2 변형 검토

- 표준 SM-2 vs FSRS (최신 Spaced Repetition 알고리즘) 비교
- FSRS는 더 정교한 망각 곡선 모델링 가능
